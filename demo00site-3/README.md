# Neural Vendas - Modern SaaS Website

A modern, responsive sales website for Neural Vendas, an AI-powered sales agent platform for businesses. This website is built with HTML, CSS, and vanilla JavaScript, featuring a sleek design with dark blue, white, and teal color scheme.

## Features

- **Fully Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional interface with smooth animations
- **Interactive Elements**: Navigation, testimonial slider, FAQ accordion, pricing toggle
- **Performance Optimized**: Fast loading with minimal dependencies
- **Cross-Browser Compatible**: Works on all modern browsers

## File Structure

- `index.html` - Main HTML structure
- `styles.css` - Complete styling with responsive design
- `script.js` - JavaScript for interactivity and animations

## Design Elements

- **Color Scheme**: Dark Blue (#0a2540), White (#ffffff), Teal (#39c4b8)
- **Typography**: Poppins font family (via Google Fonts)
- **Icons**: Font Awesome icons

## Sections

1. **Hero**: Main banner with call-to-action
2. **Clients**: Showcase of client logos
3. **Features**: Key product features in a grid layout
4. **How It Works**: Step-by-step process explanation
5. **Pricing**: Pricing plans with monthly/annual toggle
6. **Testimonials**: Customer testimonials with slider
7. **CTA**: Call-to-action section
8. **FAQ**: Frequently asked questions with accordion
9. **Contact**: Contact form and information
10. **Footer**: Site navigation, newsletter signup, and legal links

## JavaScript Functionality

- Smooth scrolling navigation
- Mobile menu toggle
- Scroll animations
- Pricing toggle (monthly/annual)
- FAQ accordion
- Testimonial slider
- Form validation
- Responsive adjustments

## How to Use

1. Download all three files (`index.html`, `styles.css`, and `script.js`)
2. Keep them in the same directory
3. Open `index.html` in a web browser to view the website

## Customization

### To change colors:

Edit the CSS variables at the top of the `styles.css` file:

```css
:root {
    --primary-color: #0a2540;
    --secondary-color: #39c4b8;
    --accent-color: #4d7cfe;
    /* other variables */
}
```

### To add/modify content:

Edit the corresponding sections in the `index.html` file.

### To modify animations or interactions:

Edit the JavaScript functions in the `script.js` file.
